# 问答、引用与回答缓存需求

## M09-R01

访客每轮先经traffic-guard验证并消费AdmissionPermit；任何新模型调用全部由MG计费与控制额度。

验收规格：契约验证行为：访客每轮先经traffic-guard验证并消费AdmissionPermit；任何新模型调用全部由MG计费与控制额度。；实现阶段才可执行验证，不在设计阶段宣称通过。

## M09-R03

回答缓存保留自动写入和人工精选；只有已补全且意思完整的问题才查/写cache。精选优先且无TTL，记忆版本改变不使精选失效；撤回/删除/引用hash变化仍失效。

验收规格：契约验证行为：回答缓存保留自动写入和人工精选；只有已补全且意思完整的问题才查/写cache。精选优先且无TTL，记忆版本改变不使精选失效；撤回/删除/引用hash变化仍失效。；实现阶段才可执行验证，不在设计阶段宣称通过。

## M09-R04

缓存canonical基准语言问题跨语言共享；默认AI同义判断（候选cosine≥0.8最多3项），可选严格相似度阈值；不以rerank相关性判断同义。每语言答案单独保存，缺语言由快速档自动翻译后存储。

验收规格：契约验证行为：缓存canonical基准语言问题跨语言共享；默认AI同义判断（候选cosine≥0.8最多3项），可选严格相似度阈值；不以rerank相关性判断同义。每语言答案单独保存，缺语言由快速档自动翻译后存储。；实现阶段才可执行验证，不在设计阶段宣称通过。

## M09-R05

验收规格：契约验证行为：流中引用必须来自knowledge返回ID；逐引用输出前权威验证，终态完成前再次验证；撤回后不再输出新内容，已发内容标invalidate。；实现阶段才可执行验证，不在设计阶段宣称通过。
