## 只读文档 agent

问答与隔离调试台共用原生工具调用流程。主模型结合当前页、全站概括、记忆和历史，自主选择查阅路径，收到工具结果后继续判断是否需要更多材料。前置问题补全、风险准入、缓存资格和引用校验继续在程序中执行；闲聊、离题和纯提示注入禁用工具。

| 工具 | 读取范围 | 结果 |
|---|---|---|
| `read_guide` | 全站或一个公开文档分区 | 分层 `AGENTS.md`、版本与目录续读位置 |
| `search_documents` | 当前公开知识索引 | 混合检索片段、文档身份与真实引用 |
| `read_document` | content 当前发布正文 | 正文分页、大纲、关联文档 ID 与真实块引用；不等待建索引 |

全站指南在提问时预载；分区按需展开。指南由 knowledge 用当前公开目录和匹配内容哈希的已有摘要生成，浏览不触发模型重写，也不修改文章。指南是导航资料，系统规则与授权始终由服务端决定。

通用循环在 `libs/platform/modelagent`；本域装配工具和原问答身份。工具调用的完整参数在完成事件后才执行；每个调用都有对应结果。同一轮重复读取复用已取材料，错误结果允许重试；持续空转、取消、截止时间和策略上限控制终止。默认最多 12 轮查阅、48 次工具调用，随后关闭工具完成回答；管理员自定义上限保留。材料分页与旧工具正文移出只由实际模型窗口决定。

访客所在页面作为成对的预读工具消息输入，窗口不足时可移出并重新读取。原生过程存入独立的 `messages.agent_messages_json`；访客原话始终是 user 文本。历史正文在重放前批量核对当前发布版本，撤回或修改后停止重放；旧式材料缺完整来源身份时只保留原问答。最终引用仍回到 content 和 public-site 核对。
