# 需求与边界

保持 D21/D35 账号产品：唯一超管、账号名口令登录、10项功能授权、初始密码强改与服务器恢复；独立私有身份服务。

| ID | 行为要求 | 验收判定 |
|---|---|---|
| M02-R01 | 保留首次无初始化码注册与唯一超管 | 第一个竞争事务成功为唯一superadmin；之后无注册入口；超管永不可停用/删除 |
| M02-R02 | 保留账号口令与强改规则 | 账号名不可改；至少8位；新口令两遍且不同旧；初始口令只看改密；其他设备失效 |
| M02-R03 | 保留10项全站功能权限默认全选 | 无文档scope/角色继承；超管专属项不能赋予子账号 |
| M02-R04 | 保留服务器查账号/重置超管 | 私有明文account-index可查；固定reset文件提交后删除；不新增邮箱恢复/MFA |
| M02-R05 | 即时撤销与安全cookie | disabled/deleted/permission change旧session立即失效，SameSite=Strict和Origin核对 |
| M02-R06 | 恢复许可不能随业务导入失效 | 批准范围限定控制操作；controltrust不被快照覆盖；所有旧session在恢复后失效 |

每项当前状态均为未实现、未执行验收。
