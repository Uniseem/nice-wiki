# 主系统后续工作规则

本模块R1实施中。实现前先阅读 README 索引与本模块四份 contracts；约束级函数（HTTP处理、事件、任务与启动入口）按 implementation 的签名、输入、输出、步骤、错误、副作用、授权、并发、幂等及依赖实现；参考级函数可在实现时调整，交付时同步合同（ADR0002）。

产品功能按 old 的产品设计与已确认 ADR（后续 D55 优先）保留；允许只读核对这些产品文档，不能读取或复制 old 业务源码、文件/函数划分或实现耦合。只改架构、私有数据归属和部署。R1实施中：按 docs/plan.md 工作包与本域合同创建源码；Go 代码记 implemented 前须 make build 通过（全部经用户自部署GitLab CI执行，尽量三个并行任务；连接与凭据仅从用户指定私有机器管理仓库读取且不入本仓库，优先专用编译Runner；GitLab不可用时记录blocked，未经用户当次明确授权不得回退本机或SSH编译）；测试/样例按 ADR0006 默认不写；不执行真实接口/模型；push 须用户当次授权。业务验收保持未勾选。

服务只写私有存储；正文文件与持久决定日志的权威按 data/workflows 执行。跨域调用只能引用生产方 operationId/types；新增公共类型/权限由根统一登记。新增 schemaVersion 必须声明迁移与拒绝策略，不能静默抛弃未知字段。

业务验收状态始终保持未执行，直到后续明确获得实现/验证授权并具备证据。
