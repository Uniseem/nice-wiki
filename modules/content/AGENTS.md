# 文档生命周期后续工作规则

本模块当前仅设计阶段。未来实现前先阅读 README 索引与本模块四份 contracts；每个未来手写/私有函数须按 implementation 登记签名、输入、输出、步骤、错误、副作用、授权、并发、幂等及依赖。

产品功能按 old 的产品设计与已确认 ADR（后续 D55 优先）保留；允许只读核对这些产品文档，不能读取或复制 old 业务源码、文件/函数划分或实现耦合。只改架构、私有数据归属和部署。不得读取 vps.txt。当前授权仅重建 main 文档与机器契约：不创建业务源代码，不写测试/样例，不执行真实接口/模型，不 push。

服务只写私有存储；正文文件与持久决定日志的权威按 data/workflows 执行。跨域调用只能引用生产方 operationId/types；新增公共类型/权限由根统一登记。新增 schemaVersion 必须声明迁移与拒绝策略，不能静默抛弃未知字段。

业务验收状态始终保持未执行，直到后续明确获得实现/验证授权并具备证据。
