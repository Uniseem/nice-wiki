# 文档生命周期后续工作规则

本模块R1实施中。实现前先阅读 README 索引与本模块四份 contracts；约束级函数（HTTP处理、事件、任务与启动入口）按 implementation 的签名、输入、输出、步骤、错误、副作用、授权、并发、幂等及依赖实现；参考级函数可自由调整，不用回写合同（ADR0002）。

产品功能按 old 的产品设计与已确认 ADR（后续 D55 优先）保留；允许只读核对这些产品文档，不能读取或复制 old 业务源码、文件/函数划分或实现耦合。只改架构、私有数据归属和部署。流程以根 AGENTS.md 为准：本地 `make build`/`make check` 通过即可提交，可在本地启动服务验证；测试、真实模型调用和推送按根规则处理。

服务只写私有存储；正文文件与持久决定日志的权威按 data/workflows 执行。跨域调用只能引用生产方 operationId/types；新增公共类型/权限由根统一登记。新增 schemaVersion 必须声明迁移与拒绝策略，不能静默抛弃未知字段。
