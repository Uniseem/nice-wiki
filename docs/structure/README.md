# 文件结构契约

实际文档/工具与未来业务源码分开。根框架的实际路径见 [框架文件清单](framework.json)，模块未来源码见各域contracts/implementation.json与docs/files.md。main不创建未来源码，目录存在不代表实现完成。

所有后续文件、生成来源、迁移和函数职责均须登记。除用户明确授权重建外，结构外增加/移动/删除/改名/职责变更先确认，参照 [合同修改手册](../playbooks/change-contract.md)。

每域总入口README→九份子文档→四份机器合同；所有具体函数见 [函数登记要求](functions.md)。全文资料还须一致描述错误、状态迁移、版本和反向恢复，不用数量代替验收。
