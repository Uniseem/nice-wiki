# 文件与函数登记要求

每个未来手写Go/TypeScript/Vue文件有固定用途和函数清单；纯类型/配置文件声明没有行为，生成文件声明来源而不手写。私有辅助函数和界面事件处理同样登记。

函数必须写：唯一ID、精确签名、每个参数名与类型/约束、每个返回值含义、作用、实际分支步骤、可能错误、数据/网络/费用副作用、授权、幂等、并发锁/租约/CAS，以及所调用同域函数或跨域operationId。

实现时按contracts/implementation.json逐项填入登记文件；不能临时创造未登记helper、状态、字段或备用调用。若发现规格缺失，先修机器合同和子文档。函数契约能够降低猜测，但正确性仍需设计审阅和已授权的行为验收。

全局检查脚本自己的入口/工具职责见 [工具函数合同](tooling.md)。
