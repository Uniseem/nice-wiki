# 总架构

## 服务与层次

十五服务独立进程、独立发布版本、私有数据空间。入口 portal 转发同源 HTTP 与 SSE，组织后台壳，不承载内容、问答、翻译算法。identity 服务发行服务身份和用户授权上下文；每域再次校验允许的调用方、操作权限、站点、会话版本和数据代次。

每模块按入口适配器 → 用例服务 → 领域规则 → 存储/远程端口组织。所有未来文件和函数已在本模块实现契约登记，处理函数只做协议转换，领域函数负责校验和状态变化，存储函数负责原子操作和幂等记录。后端使用 Go 精确签名，界面使用 Vue 3 / TypeScript；语言类型登记是架构契约，不复用旧源代码。

## 数据所有权

content拥有正文、修订、发布可见性、草稿与树；media拥有资源；localization拥有译文与术语；memory拥有记忆；identity拥有账号与会话；model-gateway拥有密钥、渠道与钱账；traffic-guard拥有行为状态；jobs拥有任务与事件；analytics拥有聚合与审计；data-protection拥有归档与镜像；site-config拥有全站配置、dataEpoch和维护状态；公开交付只拥有投影。

文件存储是所属服务内部实现，服务 API 才是跨机器协议。元数据端口要求事务、CAS、唯一键和租约；单实例可采用私有 SQLite，多副本实施须明确采用具备多实例事务的数据库并确认依赖，不能把网络共享 SQLite 当扩容。存储引擎工程选型单列为实施门槛，不允许改变业务事务契约。

## 正常运行与控制流程

基础编辑、预览、人工元数据发布无需 AI。问答、翻译、索引和记忆助手按能力配置开启。服务健康不等于全部业务能力可用，能力列表明确未配置、已就绪、暂不可用。

发布持久完成后投递带修订事件，索引/翻译/公开投影独立更新。风控签发请求范围准入，AI网关校验签名并唯一处理额度；风控不反向查模型费用，统计不控制实时预算。

恢复是单独控制流程（[ADR0003](adr/0003-restore-by-restart.md)）：site-config进入维护→各域安全屏障→各域把备份归档暂存到自己的restore目录（不动active）→data-protection持久写切换决定→各服务由进程守护重启，启动时换入暂存数据并登记回执→全部回执与就绪后解除维护。维护期间不开放业务请求，不暴露混代；切换后失败可整体换回。

## 单仓与独立交付

单仓便于契约审阅，每个模块只构建自身登记文件和版本化契约客户端，不要求其他模块重编译。前端域页面以manifest接入portal；公共纯类型和视觉令牌可按版本固定，不共享业务状态或跨域源导入。拓扑地址仅配置，不硬编码。

设计从边界和需求开始，尚无业务实现。旧分支的产品设计是功能需求基线，旧代码不是实现结构参考；不自动迁移旧运行数据。

## 入口、公共库与部署（[ADR0004](adr/0004-wiring-and-service-identity.md)、[ADR0005](adr/0005-engineering-and-deployment.md)）

portal.ProxyRequest 是浏览器访问后台与公开 API 的唯一入口：按生成的路由表匹配，执行维护门禁、同源与 CSRF、身份与预授权，对标记 x-admission 的公开 AI 请求先向 traffic-guard 申请准入，再以服务断言与委托证明转发，并流式回传。公开页面由 public-site 直接输出。

各服务共用的机制（服务身份、操作上下文、outbox/inbox、订阅与任务循环、模型调用、恢复换目录、进程模板）只在 `libs/platform` 实现一次，服务的入口函数只装配本域参数。部署配置集中在 `deploy/`：单机 Docker Compose 加 Caddy，HTTPS 只在 Caddy 终止。
