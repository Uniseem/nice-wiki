# 按模块实施

1. 读模块 README.md 和 contracts/，找到要实现的接口或流程对应的约束级函数（HTTP 处理、事件处理、任务执行、启动入口），照签名和行为实现。
2. 内部辅助函数自由拆分，不登记、不回写合同。
3. 跨服务公共机制先用 libs/platform 已有的实现（运行状态客户端、请求校验、outbox/inbox、服务断言），没有的就在 libs/platform 里补一次，不在各域复制。不跨域导入内部代码，不手改生成文件。
4. 本地跑 `make build`。能启动的服务在本地起起来，用 curl 或浏览器验证。
5. 完成后提交，并更新根 STATUS.md 的"现在能用什么 / 下一步"。
