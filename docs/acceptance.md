# 设计与业务验收

设计机械检查验证文件索引、签名/类型引用、operation处理函数、权限、事件、依赖和链接。它不证明状态算法正确、不保证代码或分布式行为无缺陷，人工仍要审阅各域流程与跨域事务。

业务实施前逐模块核对所有需求都能映射到类型、API、文件和函数；所有状态有进入/退出条件及恢复路径，所有网络副作用有超时/取消/幂等规则。没有模糊“按需实现”的缺口时才接受规格。

各模块acceptance.md描述预期行为，不作为新增/修改测试或真实接口/模型调用授权。当前没有业务代码，所有业务验收保持未通过。后续只按具体高风险缺陷提出最小普通回归，单独获准后才建立测试文件；不设覆盖率目标或全量快照。

全站验收重点：基础无AI初始化/编辑/发布；权限及预览隔离；撤回与缓存门禁；并发/重放/旧修订；费用未知与取消；人工译文保护；备份全域切代；缺依赖的明确失败；域独立构建部署与接口兼容。没有实际证据不打勾。
