# D49. 回答缓存的细化：两层匹配、默认 AI 判断、分区与校准

- 状态：✅ 已定
- 日期：2026-10-12
- 补充：D25

详见 [design/ai-qa.md](https://github.com/Uniseem/nice-wiki/blob/b8190c7/docs/design/ai-qa.md) 的"问答记录与回答缓存"。依据见 [reference/README.md](https://github.com/Uniseem/nice-wiki/blob/b8190c7/docs/reference/README.md) 的缓存部分。

- 两层匹配：先精确匹配（规范化后的哈希），再语义匹配。对话的第一个问题在前置模型之前就做精确匹配；追问在前置模型补全上下文之后。
- 语义匹配默认用"AI 判断"，"相似度阈值"作为可选的省钱方式。
- 不采用"重排模型复核"：重排模型判断的是"相关"而不是"同义"。
- 分区：嵌入模型（更换时整体清空）、问答记忆的版本。**不按语言分区**，缓存本来就跨语言共享。
- 只有前置模型判定为意思完整的问题，才查缓存、写缓存。
- 指标与校准：仪表盘显示命中率和疑似误命中；后台根据相似度分布给出阈值建议。
