# D46. 长期记忆：独立模块，统一维护，按需取用

- 状态：✅ 已定（标 🟡 的细节为默认做法）
- 日期：2026-10-12

详见 [design/memory.md](https://github.com/Uniseem/nice-wiki/blob/b8190c7/docs/design/memory.md)。

- 长期记忆是和"模型接入"并列的独立功能模块：统一维护一套记忆，问答、翻译、刷流判断、描述生成等任务按需取用。
- 记忆条目是 `data/memory/` 下的 Markdown 文件，纳入 git。内置条目：项目概述（自动维护）、品牌与语气、问答口径、翻译通用规则、各语言的翻译规则（按需创建）。
- 每个任务一次注入的记忆总量不超过 5KB。
- 任务清单只定义一次（`server/internal/aitask/`），模型接入和长期记忆共用。
- 管理员可以和记忆助手对话，由助手整理成条目；术语映射写进术语表而不是记忆。修改以差异形式展示，确认后保存。🟡
- 记忆会注入公开问答，必须当作可能被公开的内容，不能存放内部或敏感信息。
- 记忆和缓存是两个独立的模块。唯一的联动：问答记忆变化后，按旧记忆生成的缓存回答不再命中。🟡
- 翻译规则变化后不自动重译，提示预估费用由管理员决定。🟡
- 新增"AI 记忆"权限。🟡
- 影响：D22 里的"站点概述"改为记忆里的"项目概述"条目；原"回答风格"设置并入"问答口径"条目；翻译流程额外注入记忆和相邻块的现有译文。
