# D55. 初始化不依赖 AI，渠道在独立模块配置

- 状态：✅ 已定
- 日期：2026-10-13
- 部分取代：D21、D44 的初始化渠道要求；模型管理和权限约定继续有效。

初始化流程改为：注册超管 → 站点信息 → 基准语言 → 完成。初始化不要求填写 AI 渠道、密钥、模型或档位，也不进行连接探测和模型调用。

AI 渠道已有独立的模型管理模块，渠道、密钥、模型目录及五档分配均在该模块由超管后续配置，不在初始化向导重复维护入口。

没有渠道也能完成初始化，进入后台创建、编辑、预览和发布文档。快速、精确、嵌入等 AI 启用条件未满足时，AI 保持关闭并显示缺项，不能阻塞基础文档功能，也不能自动创建假渠道或调用模型。

后端完成初始化时移除渠道数量前置条件；前端向导只保留站点和语言两步，语言保存后即可完成。已有渠道、密钥、账号和初始化状态保留，不为新流程重置数据。旧 `ChannelStep.vue` 不再由向导挂载，文件暂保留，本决策不包含删除、移动或改名。

理由：文档站的首次使用应独立于可选 AI 能力；渠道已有专门管理界面，初始化强制登记会重复配置职责并阻塞无 AI 的文档站。

实施映射为重新打开 P2-02；设计和结构契约同步本结论。本轮先记录，代码和线上旧向导尚未修改；不新增测试或调用真实模型。
