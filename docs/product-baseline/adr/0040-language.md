# D40. 注释、提交信息、说明文件都用中文

- 状态：✅ 已定
- 日期：2026-10-12

- 代码注释、提交信息、`AGENTS.md`、所有文档都用中文。
- 变量名、函数名等标识符用英文。
- 提交信息的类型前缀用英文：`feat`、`fix`、`docs` 等，格式为 Conventional Commits，并带上任务编号，例如 `feat(server): 文档发布时写入 git 记录 [P2-03]`。
