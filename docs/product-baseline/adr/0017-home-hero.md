# D17. 首页：全屏主视觉，后台可配置

- 状态：✅ 已定
- 日期：2026-10-12

默认首页的首屏：
- 正中是大号的主标题，后面压着一行很大的半透明背景字 `Welcome To`。
- 背景可以是纯色、图片、动图或视频，上面加一层遮罩，保证文字看得清。

- 主标题下面有副标题和 0–3 个按钮。
- 首页只有这一屏，下面不放其他内容。

以上全部可以在后台修改。详见 [design/home.md](https://github.com/Uniseem/nice-wiki/blob/b8190c7/docs/design/home.md)。
