# D12. URL 带语言前缀，只在根路径自动跳转

- 状态：🟡 倾向（可以推翻）
- 日期：2026-10-12

- 所有语言都用 `/<lang>/...` 的形式，包括基准语言。
- `/` 根据 cookie 和 `Accept-Language` 返回 302 跳转。
- 带语言前缀的页面不强制跳转，原因：SEO，以及分享出去的链接要保持稳定。
- 每个页面输出 `hreflang` 标签和 `x-default`。
