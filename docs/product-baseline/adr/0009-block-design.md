# D9. 块级设计：只做编辑器，不做知识管理

- 状态：✅ 已定
- 日期：2026-10-12

- 每个块有稳定的 ID，用于增量翻译、AI 引用、锚点链接。
- 不做块引用、反向链接、嵌入块。
- 第一版的块类型：常规块（标题、列表、表格、代码、提示框等），以及图片、附件、公式、Excalidraw 画板、超级块（多栏）。
- 站内链接存文档 ID，渲染时转换成当前语言的地址。
