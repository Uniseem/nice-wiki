# D27. 后台功能与文档生命周期

- 状态：🟡 倾向（可以推翻）
- 日期：2026-10-12

详见 [design/admin.md](https://github.com/Uniseem/nice-wiki/blob/b8190c7/docs/design/admin.md)。要点：
- 文档生命周期：
  - 草稿、发布、撤回、回收站；
  - 发布前可以预览；
  - 已删除文档的 URL 返回 410，也可以指定跳转到其他文档；
  - 编辑冲突检测。
- 资源库：文件不自动删除，只列出当前没有被引用的文件，由你手动清理。
- 模型配置：每个角色单独选择模型，可以设备用模型。
- 新增语言或重建索引之前，先显示预估费用。
- 问答调试台：逐步展示检索和回答的中间结果，用来调参。
- 仪表盘：花费、问答量、缓存命中率、任务队列、翻译进度。
