# D47. 翻译流水线：小批次、逐级降级、翻译记忆、术语抽取

- 状态：✅ 已定
- 日期：2026-10-12

详见 [design/i18n.md](https://github.com/Uniseem/nice-wiki/blob/b8190c7/docs/design/i18n.md) 的"翻译流程"。依据见 [reference/README.md](https://github.com/Uniseem/nice-wiki/blob/b8190c7/docs/reference/README.md) 的翻译部分。

- 整篇原文作上下文，本批要翻译的块用标签圈出（translation-agent）。
- 分批：每批默认约 1000 token，后台可调；只在块边界切、各批均衡、优先在标题处切。
- 同一篇文档的各批按顺序翻译，后面的批次带上前面批次的译文。
- 校验与降级：块 ID、占位标签、译文不等于原文 → 对半切分 → 逐块翻译 → 仍失败的列在后台。
- 翻译记忆：原文相同且长度达到门槛（默认 20 字）的块复用已有译文。
- 自动术语抽取：首次翻译时抽取，**直接写进全站术语表**（用户选择），标记来源为"自动"，手动词条优先，可以整批撤销。
- 术语表符合度检查：带提醒重译一次，仍不符合则标记待复核。
- 显示原文代替译文时，页面顶部提示"部分内容尚未翻译"。
- 反思润色：按语言开启，默认关闭。
