# D20. URL 用可读路径

- 状态：✅ 已定
- 日期：2026-10-12

- 形式为 `/zh/guide/install`：路径名按文档树逐级拼接，所有语言共用同一个路径名。
- 第一次发布时由模型根据标题生成英文路径名，可以手动修改。
- 旧路径 301 跳转到新路径，跳转表存在 `data/redirects.json`，纳入 git。
