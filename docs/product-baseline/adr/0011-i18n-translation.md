# D11. 多语言：基准语言 + 大模型全站翻译

- 状态：✅ 已定
- 日期：2026-10-12

详见 [design/i18n.md](https://github.com/Uniseem/nice-wiki/blob/b8190c7/docs/design/i18n.md)。

- 初始化时指定基准语言（默认中文），后台勾选多种目标语言。
- 以块为单位做增量翻译，译文沿用原文的块 ID。
- 有术语表；可以人工修改译文，修改过的译文在原文变化时标记为待复核，不会被覆盖。🟡
- 规模：几百篇文章。
