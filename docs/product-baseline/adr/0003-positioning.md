# D3. 定位：一个项目的公开文档站，由少数几个人维护

- 状态：✅ 已定
- 日期：2026-10-12

- 一个站点只对应一个项目，不区分版本，也不放多个项目。文档始终描述当前的状态。
- 访客：匿名只读，不需要注册。
- 后台：一个超级管理员，加上超管创建的若干账号（见 D21）。

访客不需要账号体系，也不需要编辑审核。代价是公开站点要认真考虑 SEO 和访问速度。
