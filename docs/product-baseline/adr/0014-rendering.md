# D14. 公开页面由 Go 渲染，交互部分用 Vue 挂载

- 状态：✅ 已定
- 日期：2026-10-12

- 公开页面：Go 输出完整 HTML，发布时渲染并缓存。AI 问答、语言弹窗等有交互的部分，用 Vue 组件挂载到页面上。
- 后台：Vue 单页应用。

块的样式由编辑器（Tiptap）和 Go 渲染器各实现一份。两边共用同一套 CSS 类名，并用对照测试保证输出一致。
