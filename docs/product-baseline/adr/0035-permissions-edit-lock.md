# D35. 权限按功能分配，编辑时加锁

- 状态：✅ 已定
- 日期：2026-10-12

- 超管创建账号时勾选权限，默认全部勾选。权限只按功能分配，不按文档范围。
- 密钥、花费上限、可信代理、账号管理、备份恢复、操作日志等，永远只有超管能操作。
- 编辑锁：有人在编辑一篇文档时，其他人只能查看；关闭页面或长时间不操作，锁自动释放；超管可以强制释放。
- 操作日志：记录发布、删除、设置修改、账号变动、登录。只有超管能查看。
