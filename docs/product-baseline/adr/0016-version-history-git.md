# D16. 版本历史：在 data/ 目录里内置 git

- 状态：✅ 已定
- 日期：2026-10-12

- 用 go-git 实现，不依赖系统里的 git。
- 每次发布提交一次；后台可以查看历史、对比差异、回滚；可以推送到远程仓库做备份。
- 纳入 git 的：`docs/`、`i18n/`、术语表、站点设置。
- 不纳入 git 的：`wiki.db`、`drafts/`、`assets/`、`config/`。
- 提交的作者就是执行发布的账号。
