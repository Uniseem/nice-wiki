# 后台功能清单（草案）

> 状态：讨论中。对应决策记录 D27。下面标 🟡 的是默认做法，可以推翻。

## 文档管理

### 文档树

新建文档、拖拽调整顺序和层级、重命名、修改路径名。

### 文档的生命周期 🟡

```
新建 ─▶ 草稿 ─发布─▶ 已发布 ─撤回─▶ 草稿（公开页面下线）
                     │
                     └─删除─▶ 回收站 ─彻底删除─▶ 只剩 git 历史
```

- **发布前预览**：用公开页面的样式渲染草稿，只有管理员能看到。
- **撤回发布**：公开页面下线，文档变回草稿。
- **删除**：文档进入回收站，可以恢复。已发布的文档被删除后：
  - 原来的 URL 返回 410（表示永久移除），搜索引擎会尽快把它从收录里去掉；
  - 也可以在删除时选择一篇文档，让旧 URL 跳转过去。
- **编辑锁**：有人在编辑时，其他人只能查看（见 accounts.md）。同一个人在两个浏览器标签里打开同一篇文档时，靠草稿的版本号检测冲突：后保存的那个会收到提示，避免互相覆盖。

### 文档属性

- 标题、路径名
- **SEO 描述**：发布时由模型根据正文生成，可以手动修改，会进入翻译流程。
- **分享图**（Open Graph）：默认使用站点的分享图，每篇文档可以单独设置。
- 公开页面显示"最后更新于"，时间取自 git 记录。

### 粘贴与上传 🟡

- 从 Word、网页、Markdown 粘贴内容时，自动转换成对应的块，并清理多余的格式。
- 粘贴剪贴板里的图片、拖入文件时，自动上传。

### 导入

第一版不做导入，所有内容在编辑器里从零开始写。

## 资源库 🟡

- 列出所有图片、附件、视频、画板，每个文件都能看到被哪些文档引用。
- **文件不会自动删除**：历史版本可能还在引用它，自动删除会让回滚后的文档缺图。
- 后台单独列出"当前没有被引用的文件"，由你手动清理。清理时提示：历史版本可能会因此缺失文件。

## 多语言管理

- 启用或停用语言。**启用新语言前，先显示全站翻译的预估费用**，确认后才开始翻译。🟡
- 翻译进度：每种语言的完成度、正在排队的块、待复核的人工译文。
- 对照编辑：左边原文、右边译文，按块对齐，可以直接修改译文。
- 术语表。

## AI 管理

### 模型接入 ✅

有一个专门的界面，用来接入各厂商的模型渠道、把模型分配到档位（快速、精确、视觉、嵌入、重排）和任务。详见 [ai-models.md](https://github.com/Uniseem/nice-wiki/blob/b8190c7/docs/design/ai-models.md)。

按 [D55](https://github.com/Uniseem/nice-wiki/blob/b8190c7/docs/adr/0055-setup-without-ai.md)，初始化不要求 AI 渠道，该独立界面承担后续配置；没有渠道时也可完成初始化和使用文档管理。

### 长期记忆 ✅

独立的功能模块：统一维护一套记忆（项目概述、品牌与语气、问答口径、翻译规则……），问答、翻译、刷流判断等功能按需取用；可以和记忆助手对话来整理。原来的"回答风格"并入其中的"问答口径"条目。详见 [memory.md](https://github.com/Uniseem/nice-wiki/blob/b8190c7/docs/design/memory.md)。

### 问答调试台 🟡

在后台输入一个问题，逐步展示中间结果：
- 前置模型的分类和改写
- 召回了哪些块、各自的分数、重排后的顺序
- 检索员的核查结论
- 最终交给聪明模型的材料
- 每一步的花费和耗时

调整检索参数、更换模型时，用它来看效果。

### 其他

- 问答记录：浏览、筛选（答不上来的、被点了"没帮助"的），把某条记录设为精选回答。
- 回答缓存的配置：开关、命中方式、阈值、有效期。
- 防滥用：可疑事件、当前被封禁的 IP、手动解封。
- 花费上限。
- **重建索引**：比如更换嵌入模型之后。和启用新语言一样，先显示预估费用。

## 仪表盘 🟡

- AI 花费：按天统计，按用途分开（问答、翻译、描述生成……）

- 最近的可疑事件

## 站点设置

- 站点名称、logo、网站图标、主题色
- 首页主视觉（见 home.md）
- 页脚：版权信息、自定义链接、**ICP 备案号**（服务器在中国大陆时必须在页脚展示）
- 公告横幅：文字、链接、起止时间
- 默认分享图
- 可信代理地址、Turnstile 的密钥等：见 security-ops.md
