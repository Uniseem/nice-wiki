# 首页设计（草案）

> 状态：讨论中。对应决策记录 D17。

## 默认样式

每种语言各有一个首页（`/<lang>/`）。首屏是一个占满整屏的主视觉区：

```
┌──────────────────────────────────────────┐
│                                          │
│        W e l c o m e   T o               │  ← 背景字：很大、半透明，压在主标题后面
│            产品名称                       │  ← 主标题：大号文字，位于正中
│        一句话介绍你的产品                   │  ← 副标题
│     [ 开始阅读 ]   [ 问问 AI ]             │  ← 按钮（数量、文字、链接都可以配置）
│                                          │
│   背景：纯色 / 图片 / 动图 / 视频          │
│   + 一层可调深浅的遮罩，保证文字看得清      │
└──────────────────────────────────────────┘
```

## 后台可修改的设置

| 设置 | 说明 |
|---|---|
| 主标题 | 默认是站点名称；会进入翻译流程 |
| 副标题 | 一句话介绍；会进入翻译流程 |
| 按钮 | 0–3 个。每个按钮设置文字（会翻译）、链接（站内文档、AI 问答，或外部地址）、样式（主要 / 次要） |
| 背景字 | 默认是 `Welcome To`。它是装饰性的文字，默认不翻译，可以在后台打开翻译 |
| 背景类型 | 纯色 / 图片 / 动图 / 视频 |
| 背景文件 | 上传后按内容寻址存进 `assets/`，和其他图片附件一样 |
| 视频封面图 | 视频加载出来之前显示；减少动态效果模式下只显示它（见下文） |
| 遮罩深浅 | 0–100% |
| 文字颜色 | 浅色 / 深色，跟着背景来选 |

这些设置属于站点设置，存在文件里，纳入 git（见 D16），改动也能回滚。

## 实现要点

- **视频**：带 `autoplay muted loop playsinline` 属性。浏览器只允许静音的视频自动播放，iOS 上还必须加 `playsinline`。
- **iOS 播放视频要求服务端支持按字节范围请求**（Range）。Go 标准库的 `http.ServeContent` 自带这个能力，`assets/` 的文件都通过它返回。
- **动图**：GIF 文件很大，建议上传时同时接受 WebP、AVIF 格式的动图，体积小很多。
- **系统开启"减少动态效果"时**（`prefers-reduced-motion`），视频改为显示封面图。
- 首屏由 Go 模板直接输出，背景图片预加载，保证打开就能看到主视觉。
