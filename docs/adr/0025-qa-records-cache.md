# D25. 问答记录与回答缓存

- 状态：✅ 已定
- 日期：2026-10-12

详见 [design/ai-qa.md](../design/ai-qa.md)。

- 保存每条问答记录，不保存 IP，可以设置保留天数。
- 回答缓存：用前置模型改写后的问题匹配缓存。命中方式在后台二选一：
  - 相似度超过阈值就直接命中；
  - 先按相似度选出候选，再由 AI 判断能不能复用。
- 缓存失效：超过有效期；或者回答引用的块内容有变化。
- 缓存可以关闭。关闭后仍然保存记录，但每次都走完整流程。
- 回答下方有"有帮助 / 没帮助"按钮：被点"没帮助"的回答不进入缓存。
- 精选回答：在后台修改某条回答后标记为精选，不会过期，命中时优先使用。
