# D44. 多厂商模型接入：渠道 → 模型 → 档位 → 任务

- 状态：✅ 已定（档位分配的权限 🟡）
- 日期：2026-10-12
- 取代：D7（模型统一走 OpenRouter）；同时修改 D21 初始化向导里的"OpenRouter 密钥"一项

详见 [design/ai-models.md](../design/ai-models.md)。参考 opencode 的提供方设计。

- 后台有专门的模型接入界面，支持各大主流厂商（含国内厂商）和本地模型。
- 渠道：厂商预设或自定义，包含接口地址、密钥、请求头、超时、并发上限，可以测试连接。
- 模型目录使用 models.dev：编译时打包一份快照，运行时每天更新；手动覆盖的资料优先。
- 档位：快速、精确、视觉、嵌入、重排。每个档位是一个有序列表，第一个是主模型，后面是备用模型，可以跨渠道。分配时按能力检查。
- 任务：每种任务默认使用某个档位，也可以单独指定模型。
- 第一版支持的协议：
  - 对话：OpenAI Chat Completions 兼容、Anthropic Messages、Google Gemini；
  - 嵌入：OpenAI `/embeddings` 兼容、Gemini；
  - 重排：`/rerank` 风格。
  - Bedrock、Vertex、Azure 以后再做。
- 计费：用量 × 单价；渠道返回实际金额时优先使用实际金额。
- 权限：渠道和密钥只有超管能管理；档位和任务的分配交给拥有"AI 设置"权限的账号。🟡
