# D8. 存储布局：文件是真实数据，SQLite 存索引

- 状态：✅ 已定
- 日期：2026-10-12

参考思源笔记的做法。

- 正文：每篇文档是一个 JSON 文件，这是唯一的真实数据。
- 图片、附件等二进制文件：按类型分目录，平铺存放，文件名为 `<sha256>.<后缀>`。
  - 相同文件自动去重。
  - 文件内容不会变，可以让浏览器永久缓存。

运行时数据目录（草案，🟡）：

```
data/
├── wiki.db                  # SQLite
├── docs/                    # 基准语言正文，每篇一个 JSON，目录层级即文档树
│   ├── <id>.json
│   └── <id>/                # 该文档的子文档
├── i18n/<lang>/<id>.json    # 译文，按块 ID 组织
├── config/                  # 配置、密钥、账号（不纳入 git，见 D21）
└── assets/
    ├── images/<sha256>.<ext>
    └── files/<sha256>.<ext>
```

数据库里有两类派生数据：
- 可以从文件随时重建的：块表、关键词索引。
- 重建要调用模型、需要花钱的：图片描述、附件描述、上下文说明、向量。这些按内容哈希缓存。

所以备份时数据库也要一起备份，不能只备份文件。
