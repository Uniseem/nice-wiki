# D10. 检索方案

- 状态：🟡 倾向（可以推翻）
- 日期：2026-10-12

详见 [design/ai-qa.md](../design/ai-qa.md)。要点：

- 入库：
  - 把块组装成检索单元，按小节合并文本块；图片和附件各自单独成为单元。
  - 用模型给每个单元补一句上下文说明。
  - 同时建关键词索引（中文按二元组切分）和向量索引。
- 问答：
  - 前置模型拆分问题。
  - 每个子问题一个检索员：关键词和向量混合召回，用 RRF 合并，经过重排后由快速模型核查。重排使用重排档的模型；没有配置时由快速档代替（D44）。
  - 组装好材料后交给聪明模型，回答时引用到块。
