# D43. 仓库公开，许可证 AGPL-3.0

- 状态：✅ 已定
- 日期：2026-10-12

- GitHub 仓库 `Uniseem/nice-wiki` 设为公开。公开前检查过提交历史和文件内容，没有隐私信息（见 D42）。
- 许可证：**AGPL-3.0**，全文在根目录的 `LICENSE`。
  - 别人修改本程序后，如果用它对外提供网站服务，也必须公开修改后的源代码。
  - 所以公开站点的页脚默认显示一个"源代码"链接，指向仓库地址。
  - 用到的依赖（Tiptap、Excalidraw、KaTeX、models.dev 数据等）都是 MIT 这类宽松许可证，和 AGPL-3.0 兼容。
- 对 D4 的影响：思源笔记也是 AGPL-3.0，所以许可证不再是参考或借用思源代码的障碍，只要保留它的版权声明就行。但 D4 的另一个理由仍然成立：思源的编辑器和它的其他部分耦合太紧，没法单独拿出来用。所以 D4 不变。
