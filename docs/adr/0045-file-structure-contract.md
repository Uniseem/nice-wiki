# D45. 文件结构是契约：改结构必须先询问

- 状态：✅ 已定
- 日期：2026-10-12

详见 [structure/README.md](../structure/README.md)。

- `docs/structure/` 规定了仓库里每一个文件的用途，精确到文件，不精确到函数。写代码的 AI 助手按用途"填空"，防止各自发挥、把结构弄乱。
- **AI 助手只能创建、修改结构文档里列出的文件。增加、删除、改名、移动任何文件或目录，都必须先询问用户**，并说明改什么、为什么、影响哪些文件。
- 用户同意后，在同一个提交里同步修改结构文档；影响较大的，另外写一条决策记录。
- 文件的职责只能按结构文档里写的用途来写。某段代码不属于任何已有文件的职责时，同样先询问。
- 这条规定写进根目录 `AGENTS.md` 的硬性规定。
- 可以按约定的命名直接新增、不必询问的：决策记录和 push 记录、数据库迁移文件（只追加）、生成目录里的文件。shadcn-vue 组件、提示词、块类型、视频提供方、协议适配器等仍要先询问。
- 后台界面只有中文，不做多语言。
