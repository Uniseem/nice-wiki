# D22. AI 问答防滥用

- 状态：✅ 已定
- 日期：2026-10-12

详见 [design/ai-guard.md](../design/ai-guard.md)。

- 人机验证：使用 Cloudflare Turnstile。
- 刷流判断：
  - 程序检查提问频率和重复度；
  - 前置模型结合站点概述判断问题是否相关、是否在刷流；
  - 站点概述由定期任务让模型生成。
- 处置：
  - 可疑 → 弹窗，要求交互式人机验证；
  - 确定刷流或反代 → 封禁该 IP 的 AI 功能 10 分钟。
- 和站点无关的问题直接拒答，不进入检索，也不调用聪明模型。
- 整站每日花费上限：后台可以设置，超出后当天暂停问答。
