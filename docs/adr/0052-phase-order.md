# D52. 实施阶段的顺序：先 AI 问答，再多语言

- 状态：✅ 已定
- 日期：2026-10-12

```
第 0 阶段：工程准备（AGENTS.md、Makefile、钩子、隐私检查工具等）
第 1 阶段：地基（数据目录、文档格式、渲染器、数据库、配置、账号）
第 2 阶段：后台与编辑器
第 3 阶段：公开站点            ← 做完可以先上线只有基准语言、没有 AI 的文档站
第 4 阶段：AI 问答（含模型接入、长期记忆）
第 5 阶段：多语言
第 6 阶段：收尾（仪表盘、备份恢复、Docker、部署文档）
```

理由：AI 问答是站点最有特色的功能，而且只给基准语言建索引，不依赖翻译；多语言里和问答相关的部分（翻译缓存的回答、引用对应语言的译文）在问答完成后自然接上。

URL 的语言前缀从第 1 阶段起就按多语言的结构做，后面加多语言时不需要改地址。
