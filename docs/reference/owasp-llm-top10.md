## 它是什么

OWASP 发布的大模型应用风险清单。2025 版新增 LLM10"无节制消耗"（Unbounded Consumption），把原来的"拒绝服务"并入其中，重点是"拒绝钱包"（denial of wallet）：攻击者让你的账单暴涨。

## 和我们相关的部分

- 每次模型调用都设置输出长度上限，让单次请求的成本有上界。
- 限制输入长度、对话历史长度。
- 多层限流：按 IP、按用户、按功能，最后是每日花费的硬上限；任何一层都不够。
- **只按次数限流不够**：少量长而复杂的请求比大量简单请求贵得多，要按 token 或花费限流。
- 实时监控用量和花费，异常时报警。
- 多步骤的智能体要限制步数、工具调用次数、重试次数。

## 借鉴什么

- 补上明确的上限：问题长度、对话历史长度、每个任务的输出上限、检索员的轮数和工具调用次数、每个会话同一时间只处理一个问题。
- 按花费限流：每个 IP 每小时的花费上限，和已有的每日总上限配合。
- 仪表盘对花费异常给出醒目提示。
