## 它是什么

轻量的网站访问统计，可以自托管。

## 和我们相关的部分

- 不用 cookie，用一个无法识别个人身份的哈希来区分独立访客。
- 保留浏览器、地区、屏幕尺寸等有用的统计。

## 借鉴什么

- 同为 Go，统计的数据结构和汇总方式可以参考（D31）。
