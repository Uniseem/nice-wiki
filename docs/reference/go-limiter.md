> Go 的限流库，带标准库 HTTP 中间件。

## 它是什么

基于令牌桶的限流库，有内存存储和 HTTP 中间件（`httplimit`）。

## 和我们相关的部分

- 内存存储：设置每个时间窗口允许的令牌数和窗口长度。
- 中间件直接包住标准库的 `http.Handler`。

## 借鉴什么

- 按 IP 限制提问频率时可以直接使用，或者参考它的实现。单进程部署用内存存储就够了。

## 注意

- 按花费限流需要自己实现（它按次数计），可以在它的基础上扩展。
