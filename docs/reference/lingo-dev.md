## 它是什么

面向开发者的本地化引擎，把应用的多语言文件交给模型翻译，支持增量、术语表、品牌语气、质量检查。

## 和我们相关的部分

- **增量判断**（`packages/cli/src/cli/utils/delta.ts`）：每个键记录源语言内容的 md5，对比后分出新增、删除、修改、改名四类。"改名"是用哈希匹配出来的：内容不变、只是键变了，就沿用原译文。
- **分批**（SDK `packages/sdk/src/index.ts`）：默认每批最多 25 条（`batchSize`），每批大约 250 个英文单词（`idealBatchItemSize`），超过就切下一批。
- 请求里带 `reference`（其他语言已有的译文）和 `hints`（关于该条内容的提示）作为上下文。
- 文档里列出了品牌语气、术语表、质量检查（含术语表符合度）等功能。

## 借鉴什么

- 增量判断我们已经按块哈希设计，补上"内容相同就复用译文"：块移动或复制到别处时不必重译。
- 分批要小，按条数和字数双重限制。
- 把已有译文作为参考一起发给模型（对应我们的"相邻块现有译文"）。
- 质量检查里的"术语表符合度"：原文出现某个术语时，检查译文里是否用了规定的译法。

## 注意

- 它的引擎部分连接自家的云平台，我们只参考命令行和 SDK 的开源实现。
