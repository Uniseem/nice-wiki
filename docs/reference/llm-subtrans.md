## 它是什么

字幕按场景和批次切分后交给模型翻译。字幕要求逐行对齐、前后连贯，和我们按块翻译文档的情况很像。

## 和我们相关的部分

- 跨批上下文（`PySubtrans/SubtitleTranslator.py`）：每批翻译时带上**前面若干批的摘要**（`max_context_summaries`）、场景摘要、全片梗概和术语。模型在翻译的同时更新摘要，供后面的批次使用。
- 出错处理：优先把这一批**对半切开**分别重试（`autosplit_on_error`）；如果是撞到输出长度上限导致的错误，就**去掉上下文**再重试；还可以带着专门的"重试说明"重试（`retry_on_error`）。
- 最后对齐原文和译文，列出没有翻译成功的行。

## 借鉴什么

- 出错先对半切分重试，这是比"整批重来"更省钱也更稳的做法。
- 撞到长度上限时减少上下文。
- 最后列出失败的块，交给后台显示，而不是静默跳过。

## 注意

- 我们有整篇原文作为上下文，不需要它的"前文摘要"机制；但文档很长、超出上下文预算时，可以参考它用摘要代替全文。
