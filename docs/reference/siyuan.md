## 它是什么

本地优先的块级笔记软件，Go 后端加 TypeScript 前端。

## 和我们相关的部分

- 每篇文档是一个 JSON 文件，块级索引存在 SQLite 里，可以从文件重建。
- 编辑器 Protyle 和它的布局系统、后端接口耦合很紧，没法单独拿出来用（见 D4）。

## 借鉴什么

- 块的交互：拖拽手柄、`/` 菜单、超级块。
- 数据组织方式（D8）。

## 注意

- 同为 AGPL-3.0，许可证上可以借用代码；但编辑器耦合太紧，不移植（D4）。
