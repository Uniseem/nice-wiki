# PageIndex

> "不用向量、靠推理"的检索：先为文档生成目录树，再让模型沿着目录树找答案。

| 项目 | 信息 |
|---|---|
| 方向 | 检索问答 |
| 仓库 | VectifyAI/PageIndex |
| 许可证 | MIT |
| 主要语言 | Python |
| Star | 39.1k |
| 最近更新 | 2026-10 |

## 它是什么

把文档整理成层级目录树，检索时由模型阅读目录、逐层推理定位到相关章节，不依赖向量相似度。

## 和我们相关的部分

- 主张"检索真正需要的是相关性，而相关性需要推理"，在需要专业理解的文档上效果好。
- 有面向整个文档集的文件级树索引。

## 借鉴什么

- **作为检索员的补充工具**：我们的文档本来就是一棵树，各篇有标题和小节标题。可以给检索员加一个"查看目录树"的工具，让它在混合检索不够时沿着目录查找。两种方式互补。

## 注意

- 完全靠推理检索的成本和延迟都更高，不适合作为主路径。
