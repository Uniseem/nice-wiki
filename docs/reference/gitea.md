## 它是什么

自托管的代码托管平台。页面由 Go 的模板渲染，交互复杂的部分用 Vue 组件。

## 和我们相关的部分

- 仓库里有 588 个 Go 模板（`templates/**/*.tmpl`）和 23 个 Vue 组件（`web_src/js/components/`），前端入口是 `web_src/js/index.ts`，用 `vite.config.ts` 构建。
- 发布为单个可执行文件。

## 借鉴什么

- **我们公开站点的架构样板**：怎么在 Go 模板里放挂载点、怎么把初始数据传给 Vue 组件、开发时怎么和 Vite 配合、构建产物怎么嵌入程序。实现时直接对照它的做法。

## 注意

- 它的体量很大，只看相关的部分：模板组织、前端入口、Vite 配置、挂载方式。
