## 它是什么

提供一系列输入、输出扫描器，在请求进出模型时检查。

## 和我们相关的部分

- 输入扫描器包括：禁止话题（BanTopics）、提示词注入（PromptInjection）、长度上限（TokenLimit）、语言检测等。

## 借鉴什么

- "禁止话题"和"长度上限"的思路已经包含在我们的前置模型和 OWASP 的上限建议里。
