# VitePress

> Vue 官方的文档站生成器，我们公开站点的布局就是参照它的样子。

| 项目 | 信息 |
|---|---|
| 方向 | 整体架构 |
| 仓库 | vuejs/vitepress |
| 许可证 | MIT |
| 主要语言 | TypeScript |
| Star | 18.4k |
| 最近更新 | 2026-10 |

## 它是什么

基于 Vite 和 Vue 的静态文档站生成器。

## 和我们相关的部分

- 默认主题是"左侧文档树 + 正文 + 右侧本页目录"的三栏布局（D19 就是照此设计）。
- "最后更新于"取自 git：对每个文件取最后一次修改它的提交时间；CI 里如果只拉取了浅历史，所有页面的时间会一样。

## 借鉴什么

- 布局、本页目录的滚动高亮、上一篇/下一篇的交互细节。
- "最后更新于"的取法和我们一致；我们的 data 仓库是完整历史，没有浅克隆的问题。
