## 它是什么

YouTube 嵌入的轻量替代：页面上先渲染一个看起来和播放器一样的封面，点击后才加载真正的 iframe。

## 和我们相关的部分

- 作者称渲染速度约为普通嵌入的 224 倍。

## 借鉴什么

- 我们平台视频"点击后才加载"（D24）的做法与它一致，可以参考它的结构和无障碍处理。
