## 它是什么

类型安全、持久化、嵌入式的任务队列和后台执行器。

## 和我们相关的部分

- 功能：重试与退避、定时执行、可选的结果保留、优雅关闭、事务内投递任务、不轮询数据库、工作池、捕获 panic、网页监控界面。
- 可以使用任意 SQLite 驱动，它自己的测试用的就是 modernc.org/sqlite（和我们一致）。

## 借鉴什么

- **可以考虑直接用它来实现 `internal/jobs`**，而不是自己写队列。功能和我们需要的几乎一致。
