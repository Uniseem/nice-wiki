# Starlight

> Astro 的文档站框架，多语言的"回退内容"做法值得照搬。

| 最近更新 | 2026-10 |

## 它是什么

基于 Astro 的文档站框架，内置多语言。

## 和我们相关的部分

- 某种语言还没有翻译某个页面时，显示默认语言的内容，并提示"该内容尚未翻译成你的语言"。
- 每种语言一个目录，同名文件互相对应；可以设置一个不带地址前缀的"根语言"。

## 借鉴什么

- **未翻译时的提示**：我们新增的块还没有译文时会先显示原文，应该像它一样加一句提示，免得访客困惑。

## 注意

- 我们所有语言都带前缀（D12），不用它的"根语言"做法。
