# Anubis

> 用 Go 写的反爬中间件：给可疑请求出一道挑战，挡住批量抓取的机器人。

| 项目 | 信息 |
|---|---|
| 方向 | 防滥用 |

| Star | 23.3k |
| 最近更新 | 2026-10 |

## 它是什么

放在网站前面的反向代理，用一个或多个挑战（包括浏览器端的工作量证明计算）过滤机器人，保护后端资源。

## 和我们相关的部分

- 挑战在访客浏览器里运行，正常用户几乎无感，批量脚本的成本则大幅上升。
- 完全自托管，不依赖第三方服务。

## 借鉴什么

- **Turnstile 的备用方案**：Turnstile 依赖 Cloudflare，国内网络访问有时不稳定。加载失败时，可以改用自托管的工作量证明挑战，只保护问答接口。

## 注意

- 它的定位是**阻挡 AI 爬虫**，而我们欢迎 AI 爬虫读文档（D32），所以只借鉴挑战机制，用在问答接口上，**不能用在公开页面上**。
