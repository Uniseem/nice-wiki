# Umo Editor

> 基于 Vue 3 和 Tiptap 3 的国产开源文档编辑器。

| 项目 | 信息 |
|---|---|
| 方向 | 编辑器 |
| 仓库 | umodoc/editor |
| 许可证 | MIT |
| 主要语言 | Vue |
| Star | 1.6k |
| 最近更新 | 2026-09 |

## 它是什么

提供类似 Word 的在线编辑体验，专为国内用户设计，带 AI 创作功能。

## 和我们相关的部分

- 技术栈和我们完全一样：Vue 3 + Tiptap 3。

## 借鉴什么

- Vue 3 和 Tiptap 3 集成的工程写法、工具栏和菜单的组织方式。

## 注意

- 它偏向"类 Word 的分页文档"，和我们"块级 + 思源式交互"的风格不同，只参考集成方式。
