# go-git

> 纯 Go 实现的 git，我们版本历史（D16）使用的库。

| 项目 | 信息 |
|---|---|
| 方向 | 存储与运维 |
| 仓库 | go-git/go-git |
| 许可证 | Apache-2.0 |
| 主要语言 | Go |
| Star | 7.8k |
| 最近更新 | 2026-10 |

## 它是什么

不依赖系统 git 的 Go 实现，可以初始化仓库、提交、查看历史、推送。

## 和我们相关的部分

- Gitea 等项目也使用它。

## 借鉴什么

- 按设计直接使用。

## 注意

- 按文件过滤历史需要遍历提交，历史很长时可能变慢，实现"最后更新于"时要实测，必要时把结果缓存到数据库。
