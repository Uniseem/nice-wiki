## 它是什么

连接各种数据源建立索引，在聊天中检索回答。

## 和我们相关的部分

- README 强调：相比"智能体临时调用多个搜索工具"或"不建索引"的做法，事先建好索引更可靠、延迟更低、成本更低。

## 借鉴什么

- 印证我们"先建索引、再由检索员核查"的组合：索引负责快和便宜，模型负责判断。
