# Litestream

> SQLite 的持续备份工具：在后台把数据库的变化增量复制到另一个文件或 S3。

| 项目 | 信息 |
|---|---|
| 方向 | 存储与运维 |
| 仓库 | benbjohnson/litestream |
| 许可证 | Apache-2.0 |
| 主要语言 | Go |
| Star | 14.5k |
| 最近更新 | 2026-10 |

## 它是什么

以后台进程的形式运行，围绕 SQLite 的 WAL 检查点同步变化。

## 和我们相关的部分

- 只通过 SQLite 自身的接口和数据库交互，不需要修改程序。

## 借鉴什么

- **写进部署文档作为可选的持续备份方案**：比我们每天一次的定时备份更及时。程序本身不集成。

## 注意

- 只备份 SQLite，`data/` 里的文件仍然靠 git 远程推送和定时打包备份。
