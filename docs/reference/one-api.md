# One API

> 国内最流行的模型接口管理和分发系统，"渠道"这个概念就来自这类系统。

| 项目 | 信息 |

| 方向 | 模型接入 |

| Star | 37.1k |
| 最近更新 | 2026-01 |

## 它是什么

统一管理多家模型的密钥，对外提供统一接口。单个可执行文件，也有 Docker 镜像。

## 和我们相关的部分

- 渠道管理：批量创建渠道，为渠道设置模型列表，渠道分组。
- 多个渠道之间负载均衡，失败自动重试。
- 模型映射：把请求里的模型名重定向到另一个模型。
- 支持流式输出、多机部署。

## 借鉴什么

- 后台"模型渠道"页面的交互可以参考：渠道列表、测试、为渠道启用模型。
- 失败自动重试、换渠道的做法。

## 注意

- 它面向"把模型接口转卖给别人"，有用户、额度、兑换码等功能，我们不需要。最近一次更新在 2026 年初。
