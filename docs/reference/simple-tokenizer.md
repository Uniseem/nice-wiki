> 支持中文和拼音的 SQLite FTS5 分词扩展。

## 它是什么

实现了微信移动端全文检索的多音字方案，可选用 cppjieba 做更精确的词组匹配。

## 和我们相关的部分

- 它是 C++ 写的 SQLite 扩展，需要以加载扩展的方式使用。

## 借鉴什么

- 说明"SQLite 自带的分词对中文不够用"是普遍问题。

## 注意

- **和纯 Go 驱动不兼容**（无法加载 C 扩展），这正是我们选择"在 Go 里切二元组再存进 FTS5"的原因（D10）。
