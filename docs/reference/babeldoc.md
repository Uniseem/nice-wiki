## 它是什么

把 PDF 解析成中间结构，按段落交给模型翻译后再排版回去。它在"批量翻译时怎么保证不出错"上做得很细。

## 和我们相关的部分

- **批次很小**：累计超过 200 token 或者满 5 段就切开一批（`il_translator_llm_only.py`）。
- 要求模型返回**同样长度**的 JSON 数组，每项保留原来的 `id`；条数对不上就**退回逐段单独翻译**。
- 译文和原文完全相同（并且原文足够长）时，判定为翻译失败，同样退回逐段翻译。
- 只把当前这批文字里**实际出现**的术语表词条放进提示词。
- **自动术语抽取**（`automatic_term_extractor.py`）：正式翻译前，先让模型从文中抽取关键术语并给出译法，形成全文共用的术语表。
- 把文档的标题段落、最近的章节标题作为上下文提示一起发送。

## 借鉴什么

- 批次大小：按 token 和段数双重限制，宁小勿大。
- 失败降级：条数校验 → 不对就拆小 → 最后逐块翻译。
- "译文等于原文"的检查。
- 自动术语抽取：首次翻译一篇文档前先抽术语，作为待确认的术语进入术语表。
- 带上所在章节的标题作为上下文。
