## 它是什么

无界面的富文本编辑器框架，基于 ProseMirror，通过扩展定制。

## 和我们相关的部分

- 我们用到的官方扩展（唯一 ID、拖拽手柄的 Vue 3 版、Suggestion、表格、代码高亮、公式）都是 MIT 许可，版本 3.31（2026-10 查询）。

## 借鉴什么

- 官方文档和示例是第一参考。

## 注意

- 部分高级功能（如协作云服务）是商业产品，我们不需要。
