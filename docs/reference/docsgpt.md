|---|---|
| 方向 | 检索问答 |

## 它是什么

可以私有部署的 AI 平台，主打基于文档的问答，能通过小部件、兼容 OpenAI 的接口或 MCP 嵌入到产品里。

## 和我们相关的部分

- README 展示了一个用例：聊天小部件嵌在产品支持页面上，根据手册回答问题——和我们的问答浮窗是同一个场景。

## 借鉴什么

- 参考聊天小部件的交互：入口位置、引用来源的展示方式。

## 注意

- 它是一个完整的平台，体量远大于我们需要的部分，只参考交互。
