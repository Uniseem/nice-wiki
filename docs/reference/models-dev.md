## 它是什么

收录各供应商及其模型的资料，以 `https://models.dev/api.json` 提供。

## 和我们相关的部分

- 2026-10 时收录 226 个供应商。
- 供应商字段：接口地址（`api`）、文档、环境变量名、AI SDK 包名（`npm`，可用来判断协议）。
- 模型字段：价格（输入、输出、缓存读取，按百万 token 计）、上下文和输出上限、输入输出模态（能否看图）、是否支持工具调用、结构化输出、推理等。
- 国内厂商 DeepSeek、Kimi、智谱、通义、豆包、MiniMax、硅基流动都在其中。

## 借鉴什么

- 直接作为内置目录：编译时打包快照，运行时每天更新（D44）。

## 注意

- 嵌入模型和重排模型收录得不全，需要允许手动补充（已在设计中）。
