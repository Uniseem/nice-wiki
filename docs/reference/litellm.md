# LiteLLM

> 最流行的开源模型网关：统一调用 100 多家模型，带备用切换、花费统计、预算。

| 项目 | 信息 |
|---|---|
| 方向 | 模型接入 |
| 仓库 | BerriAI/litellm |
| 许可证 | 主体 MIT，`enterprise/` 目录另行授权 |
| 主要语言 | Python |
| Star | 61k |
| 最近更新 | 2026-10 |

## 它是什么

用统一格式调用各家模型的 SDK 和网关。

## 和我们相关的部分

- 路由器支持在多个部署之间重试和备用切换。
- 按项目、按用户统计花费和管理预算；有管理面板。

## 借鉴什么

- 备用切换、花费统计、预算控制的设计和我们 D44 的"档位有序列表 + 计费"一致，实现细节可以参考。

## 注意

- 它是 Python 写的独立服务，我们不引入，只参考做法。
