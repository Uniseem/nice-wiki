## 它是什么

把问题转成向量，找到相似的历史问题就直接返回缓存的回答。各个环节（向量化、存储、相似度评估、淘汰）都可以替换。

## 和我们相关的部分

- 相似度评估有多种：精确匹配、向量距离、用一个模型（ONNX）来评估两句话是否同义。
- 有研究指出它建议的阈值 0.7 效果不理想，而且最佳阈值随嵌入模型变化；另一项评测按经验选了 0.9。阈值必须按自己的数据调。
- ThoughtWorks 技术雷达提醒：要评估误命中（不该命中却命中）和漏命中。

## 借鉴什么

- 分两层：先精确匹配（规范化后的问题哈希，零成本），再语义匹配。
- 在"阈值"和"AI 判断"之间，加一种"用重排模型复核"的命中方式：重排模型就是专门判断两段文字相关性的模型，比大模型便宜很多。
- 阈值不能照抄，要提供校准工具；更换嵌入模型时必须重新校准。
