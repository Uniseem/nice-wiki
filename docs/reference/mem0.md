## 它是什么

从对话中抽取值得记住的事实，再和已有记忆比较，决定怎么更新。

## 和我们相关的部分

- 更新记忆的提示词（`mem0/configs/prompts.py` 里的 `DEFAULT_UPDATE_MEMORY_PROMPT`）让模型对每条新信息做四选一：**ADD**（新增）、**UPDATE**（更新已有的）、**DELETE**（删除已有的）、**NONE**（已经存在或无关，不变）。
- 两步走：先从对话里抽取事实，再逐条和已有记忆比对决定操作。

## 借鉴什么

- 记忆助手整理时照这个做法：先从对话里提炼出要点，再逐条判断新增 / 更新 / 删除 / 不变，自然实现去重和冲突处理（新说法和旧说法矛盾时更新或删除旧的）。
- 这些操作正好可以展示成差异，让管理员确认。

## 注意

- mem0 主要面向"记住用户个人信息"，我们的记忆是管理员维护的规则和背景，只借鉴更新流程。
