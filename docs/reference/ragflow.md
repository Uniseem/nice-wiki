# RAGFlow

> 最流行的开源检索增强生成（RAG）引擎之一，强调文档理解和可解释的切块。

| 项目 | 信息 |
|---|---|
| 方向 | 检索问答 |
| 仓库 | infiniflow/ragflow |
| 许可证 | Apache-2.0 |
| 主要语言 | Go |
| Star | 92.1k |
| 最近更新 | 2026-10 |

## 它是什么

深度理解文档结构后再切块、检索、回答，带智能体能力。

## 和我们相关的部分

- 基于模板的切块：多种模板可选，切块过程可视化、可解释。
- README 里有切块效果的演示。

## 借鉴什么

- 切块"可解释、可查看"的思路：我们的问答调试台里，应该能看到每个检索单元是由哪些块组成的。

## 注意

- 面向任意格式文件的通用引擎，我们的内容是结构化的块，不需要复杂的版面解析。
